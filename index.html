💡
IDE 使用说明： Emerald IDE 基于 Electron，包含运行时和大量依赖文件， 因此以 zip 压缩包 形式提供。 下载后请先 解压到任意目录， 再双击解压目录中的 EmeraldIDE.exe 启动。 不要在压缩包里直接运行。
从源码编译
# 克隆仓库 git clone https://github.com/Fireloader600/eml-lang.git # 编译编译器（需要 gcc / MinGW） gcc eml.c -o eml.exe -std=c99 # 构建 IDE（需要 Node.js 18+） cd emerald-ide npm install npm run rebuild npm run dist

· 编译器（eml.exe）：负责编译、运行、打包程序。
· IDE（EmeraldIDE）：图形化开发环境，内置终端和编辑器。
IDE 的构建操作会调用同目录或 PATH 中的 eml.exe，所以两个都装才能完整使用。
Beta 版本已经实现了完整的核心功能（变量、列表、函数、循环、编译、打包、IDE），可以用。但 API 和语法在正式版发布前可能还会有细微调整，建议用于学习、原型和内部工具。
Emerald IDE 基于 Electron 开发，运行时依赖大量文件（Chromium 内核、Node 运行时、各类 DLL 和资源文件）。单独一个 exe 无法运行。请下载 zip 后 解压到任意目录，再双击目录里的 EmeraldIDE.exe 启动。不要直接在压缩包里运行。
PATH 没配好。把 eml.exe 所在目录加入系统 PATH，然后重开终端。修改 PATH 后已打开的终端不会自动生效。
